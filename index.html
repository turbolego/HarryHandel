About HarryHandel

Data Sources

  • kassal.app – Norwegian grocery price comparison
  • rema.no – Rema 1000 (Reitan Retail)
  • nordby.se – Nordby (Sweden)

Norwegian Chains Covered

  • NorgesGruppen: KIWI, MENY, SPAR, Joker, Nærbutikken
  • Coop Norge: Coop Extra, Coop Prix, Coop Mega, Obs, Matkroken
  • Reitan Retail: Rema 1000

Methodology

  • Playwright headless browser scraping
  • Weekly GitHub Actions workflow
  • Products matched by normalised name
  • Prices normalised to SEK for comparison

Technical

  • Zero API keys / tokens
  • GitHub Actions + GitHub Pages
  • Playwright + Chart.js
  • Open source (MIT)
